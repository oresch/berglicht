# Herzlich Willkommen auf den Internetseiten von Reinhard Resch

Auf den folgenden Seiten können Sie sich über im Privatbesitz befindliche Baugrundstücke im Neubaugebiet "Auf der Karsonick" in der Gemeinde Berglicht informieren.

Die Baugrundstücke sind erschlossen (ohne Endausbau Straße (endgültiger Teerbelag) und können sofort bebaut werden. Die im Register Grundstücke farblich markierten Baugrundstücke werden zu dem jeweils angegebenen Preis je Quadratmeter angeboten.
